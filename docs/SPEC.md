# 多巴練習簿 — 公開版規格書

多巴練習簿是一款每解完一道計算題，吉祥物的動作、畫面演出與音樂就會增強的瀏覽器遊戲。本書針對遊玩者與家長，以及對開發、改造有興趣的人，說明目前實作的行為。數值可能因日後的調整而變更。

## 1. 概要與設計理念

目標是讓使用者每天一點一點持續計算，並確認自己相較於過去的成長。基本題即使超過時間也能繼續作答，全部解完即為100分。沒有遊戲結束。

答錯時會顯示「可惜」，可以重新作答。已獲得的星星、獎盃、演出，不會因失敗或缺席而被收回。連續紀錄有補回休息日的機制，而成長比較只顯示有改善的項目。獎勵在達成條件時解鎖，沒有抽獎或付費取得的途徑。

以日文畫面，對應小學生的計算練習與成人的使用。以智慧型手機直向畫面為主，也能用 PC 的滑鼠、鍵盤操作。不需要註冊帳號。由於是依瀏覽器分別記錄，不會與其他裝置自動同步。

## 2. 畫面與流程

### 2.1 畫面一覽

| 畫面 | 內容與主要操作 |
| --- | --- |
| 標題 | 標誌、多巴基、我的程度、其正下方的複習、1～6年級、技能樹、獎盃、收藏、今日任務、行事曆、設定、？ |
| 遊玩 | 題目、輸入格、專用數字鍵盤、答對數、可惜的次數、時鐘、多巴、連擊、進度顯示、靜音 |
| 基本結果 | 100分、時間、首次答對率、多巴、成長、技能、今日任務的結果。達成條件時的加碼關、重新作答、再次遊玩、返回標題的操作 |
| 最終結果 | 含加碼關的得分與多巴、答對數、可惜的次數、今日任務、重新作答、返回標題的操作 |
| 技能樹 | 前置關係、解鎖、練習、精通的狀態、星星、生鏽、技能的說明與練習、記錄的部分刪除 |
| 獎盃 | 分類、系列別的成就、獲得日期、條件與獎勵、篩選、即將獲得的成就 |
| 收藏 | 已解鎖演出的試看、試聽、各分類的固定或隨機 |
| 設定 | 題數、音效、音量、動作強度、示範遊玩、全部資料的重設 |

一般流程為「標題 → 基本題 → 基本結果 → 任意的加碼關 → 最終結果」。複習只到基本結果為止。結果畫面的操作按鈕固定在下緣，即使成長記錄增加，也能繼續進行下一個操作。

### 2.2 初次導引與「？」說明

初次會顯示5頁的導引。順序為開場介紹、我的程度、依年級、技能樹、推薦我的程度的引導。設定按鈕下方的「？」可重新顯示加上獎盃與收藏後的7頁說明。

以聚光燈照亮說明的對象，並視需要捲動。說明文字顯示在獨立的卡片上，多巴基則以移動、指向、表情來引導。不會以多巴基的台詞形式顯示。最後指出「我的程度」與「？」，若兩者無法同時容納於畫面內，就在卡片內顯示相同的問號圖示。

以「下一頁」「返回」「跳過」，以及最後的「開始！」來操作。Enter、右方向鍵為下一頁，左方向鍵為上一頁，Escape 為略過，Tab 為導引內的焦點移動。按下暗幕也不會關閉，導引期間無法操作背景的按鈕。

無論看到最後或略過，都會儲存為已顯示。初次導引之後，依序處理免計鐵鎚、簽到獎勵、獎盃通知。全部重設後會再次顯示初次導引。示範遊玩中與部分確認用 URL 不會自動顯示。

## 3. 模式

### 3.1 我的程度

首次為「程度測驗」。依年級、前置關係的深度順序排列技能並往下推進，若首次答對，就將出題對象與其前置技能一併設為精通、☆1。移動幅度最初為6，答對後取目前幅度的1.3倍並向上取整，最大為12；答錯後取一半並向下取整，最小為1。答錯後會退回到最後一次首次答對的位置之後的範圍。基本題結束後即成為已檢查狀態。

之後的出題依前置關係的深度、年級、技能定義順序來選擇。從已精通技能的最後6項挑選複習，複習名額為 `min(候選數, max(1, round(題數 × 0.3)))` 題。優先選擇生鏽的技能，其餘從候選中隨機挑選。若沒有已精通的技能，複習名額為0。

其餘依序重複已解鎖、未精通技能的前4項。若全部都已精通，就從所有已精通的技能中挑選。加碼關重複未精通候選的最後3項，若沒有則重複已精通的最後3項。剛完成檢查後的加碼關，從已解鎖、未精通的最前頭挑選。

### 3.2 依年級

不論解鎖狀態為何，都從所選年級的技能出基本題。排序由前置關係較淺者進到較深者，並加入亂數的擾動。作答結果也會反映到一般的熟練度。

加碼關的最初6題，重複該年級技能列中第 `floor(技能數 × 0.55)` 項之後的部分。從第7題起切換到下一個年級最前頭的技能，最多4項。6年級則繼續同一年級的後半段。

### 3.3 練習

從技能樹中選擇已解鎖的技能進行練習。若已精通，可從說明畫面開始練習。基本題為該技能，加碼關則從以該技能為直接前置的已解鎖技能中挑選。若沒有對象，就繼續同一技能。

在依年級與練習模式中，符合條件的時光膠囊有時會取代基本題中的1題。這1題可能超出指定的年級、技能範圍。

### 3.4 複習

在含答錯的問題解到最後的時點，會保存問題本身，最多40題。以問題的標題與算式作為識別碼來去除重複。中途中斷的未完成問題不會加入。

可從標題與結果的重新作答按鈕開始。從已保存清單的末尾，以設定題數與10之中較小者為上限來挑選。即使從結果的按鈕開始，也不會只限於該回的誤答，而是使用先前留下來的清單。

以首次答對重新解開的問題會從清單中刪除，再次答錯的問題則保留。全部解完即為100分，沒有加碼關。也會反映到一般的成長記錄、熟練度、今日任務。

### 3.5 示範遊玩

在設定中選擇「自動示範」即開始自動操作。將從所有技能中挑選的問題由簡單到難排列，加碼關從4年級以上的技能中挑選。使用一般的輸入、判定、演出，也會加入答錯。基本題中答錯的題數上限為 `floor(題數 × 0.2)`。

基本題、加碼關、最終結果跑完一輪後會回到標題並解除示範。點擊、按鍵操作也能結束。剛開始後的點擊有600ms的忽略時間。示範的遊玩結果不會累加到歷史、熟練度、複習、成長統計，也不會推進今日任務或獎盃的獲得。回到標題後的正常簽到處理仍會執行。

固定下來的演出在示範中也會使用，只有隨機的分類會從已解鎖中挑選。URL 的 `?demo` 是與這個自動操作不同的功能。

## 4. 單次遊玩與輸入

### 4.1 基本題與加碼關

題數為6、10、14題，初始值為10題。基本題的目標時間為 `ceil(題數 × 18 ÷ 10) × 10` 秒，6題為110秒，10題為180秒，14題為260秒。即使超過也能繼續，不會扣分。基本題的經過時間從遊玩開始到完成為止，也包含題目的切換。

「答對」是指完成到最終解的問題數，「可惜」是指受理的數字對目前的格而言是錯誤的次數。「首次答對」是指包含中途輸入在內，一次都沒有答錯而完成的問題。基本題的首次答對數除以題數的比率若在0.8以上，就可以選擇加碼關。

加碼關預設為90秒。以開始處理的時刻加上90,000ms與導入用的900ms來設定期限。並非採從最初可輸入的時刻起保證90秒的方式，題目切換期間時鐘也會前進。確認對話框期間則會停止。時間到就確定得分，並前往最終結果。未完成的問題不計分，但已受理的正確格所增加的多巴會保留。

### 4.2 數字的輸入

使用專用數字鍵盤與 PC 的數字鍵逐一輸入，並當場判定。沒有確認作答的按鈕。正確的位數會保留，錯誤的數字在下次輸入時被取代。Backspace 是刪除目前錯誤數字的操作，不會取消已答對的位數。

在智慧型手機上，會配合包含瀏覽器操作列在內的顯示區域，調整題目的留白與數字鍵盤的高度。將含0與刪除的最下排配置在下緣安全區域之上，畫面尺寸改變時也會重新計算題目的文字大小。

| 題目的形式 | 輸入順序與自動顯示 |
| --- | --- |
| 橫式 | 從答案的左邊位數開始輸入 |
| 橫式有餘數的除法 | 商、餘數的順序 |
| 加減法的直式 | 從最下面的位數開始。自動顯示進位、退位的輔助數字 |
| 乘法的直式 | 從右邊輸入部分積，若有多個部分積，合計也從右邊輸入 |
| 除法的直式 | 依商的上位、相減後的餘數、下一個商的順序。積、放下來的數字、最後的餘數0會自動顯示 |
| 小數 | 自動顯示小數點，只輸入數字 |
| 分數 | 分母、分子的順序。帶分數依整數部分、分母、分子的順序 |
| 比、文字式、概數、百分率 | 從指定空欄的左邊位數開始輸入 |

分數以事先備好的回答格式判定。3年級的同分母分數保留原本的分母，接受未約分的答案。其他分數計算則使用生成後的最簡分數、帶分數格式。並非採自由輸入等值其他表示法來判定的方式。

### 4.3 答錯與提示

錯誤的數字會使用紫色的虛線框。在同一個格答錯2次時，若有定義應參照的數字，就會加以強調、指向。第3次以後會顯示計算的途中式或九九乘法表的數列等提示。提示中可能包含相當於答案的值。

答錯會讓連擊歸0，但不會減少得分、多巴，並維持演出階段與 BGM。為了答錯音會暫時壓低 BGM，並使用有彈跳感的音效與多巴基回復的演技。

## 5. 得分、多巴、連擊

### 5.1 得分

基本題完成即為100分。設加碼關已完成的問題以0為起始編號為 `k`，則該題的加分成為 `10 + 5 × k` 分。完成 `n` 題加碼關的合計得分如下式。

```text
100 + 10 × n + 5 × n × (n − 1) ÷ 2
```

5題為200分、10題為425分、15題為775分、23題為1595分、30題為2575分。得分沒有固定上限。不會因連擊、作答速度、可惜的次數而有得分倍率或扣分。

### 5.2 多巴的計算

多巴是演出的數值，與得分不同。內部以常用對數持有數值 `L`，顯示值的原始值為 `10^L`。遊玩開始時為 `L = 0`。

基本題的基準曲線設為 `B(f) = 2.3 × clamp(f, 0, 1)^1.15`，加碼關的基準曲線設為 `X(n) = 2.3 + 3.0 × (1 − exp(−n / 10))`。

設基本題的總題數為 `N`、已完成題數以0為起始編號為 `q`、目前題目的回答格數為 `m`、本次答對的格以1為起始編號為 `s`，則該次輸入的基準增量為 `B((q + s/m)/N) − B((q + (s−1)/m)/N)`。設加碼關已完成題數為 `k`，則1格的基準增量為 `(X(k+1) − X(k))/m`。

答對時會先將連擊數 `c` 加1，再以下式反映該次輸入。

```text
倍率 M(c) = 1 + (2 − 1) × min(1, max(0, c) / 20)
新的 L = min(9.08, L + max(0.003, 基準增量) × M(c))
```

10連擊為1.5倍，20連擊以上為2倍。上限為對數值9.08，換算成原始顯示值則正好是 `10^9.08`。由於增量有最低值0.003，實際的到達值並非只由基準曲線的終點決定。最初的答對也是1連擊、1.05倍，加碼關開始時會將連擊歸0並繼承多巴。

顯示上，未滿1萬會四捨五入為整數，之後加上「萬」「億」等單位。單位內的值若未滿10則顯示到小數第1位，10以上則顯示向下取整的整數。抵達100、1000、1萬、10萬、100萬、1000萬、1億時會有里程碑的演出。一般遊玩的上限不會達到兆以上。

### 5.3 連擊的時間與顯示

每答對一個回答格就加1連擊，並跨題目累積。2連擊以上才顯示，20連擊以上顯示「多巴×2 MAX」。答錯或時間到會歸0。不過，目前的實作中，1連擊的狀態不在時間到判定的對象之內。

年級 `g` 的普通格時間為 `3000 + 600 × (g − 1)` ms，題目的第一個格會再加2500ms。年級限制在1～6，不明時以3處理。

| 年級 | 普通格 | 題目的第一個格 |
| --- | --- | --- |
| 1 | 3000ms | 5500ms |
| 2 | 3600ms | 6100ms |
| 3 | 4200ms | 6700ms |
| 4 | 4800ms | 7300ms |
| 5 | 5400ms | 7900ms |
| 6 | 6000ms | 8500ms |

在受理輸入的時點設定期限，題目切換與確認對話框不會消耗時間。剩餘時間的長條在未滿30%時會強調。10、20、30、50、75連擊，以及100以上每50連擊會大大地慶祝。5連擊以上中斷時，會短暫顯示結束時的數字。

## 6. 出題範圍與技能樹

### 6.1 範圍與生成

計算分成58項技能。依年級則為1年8、2年13、3年14、4年10、5年8、6年5。系統分為「加減」「乘除」「小數與分數」「其他」4類。所有技能的名稱、識別碼、前置、生成條件都整理在 `docs/curriculum.md`。

對象為四則計算、伴隨中途輸入的直式、小數、分數、概數、因數、倍數、計算順序、百分率、相等的比、文字的值。不出題圖形、測量、圖表、文字題、漢數字輸入。

每次依技能的條件以亂數生成。使用最近24題的簽名，以及該次遊玩內已出題的簽名來避免重複。候選生成有重試次數上限，因此在候選較少的技能等情況下可能出現重複。時光膠囊與複習是為了重現相同問題的例外。

### 6.2 顯示與解鎖

各系統分成2列，以共8列顯示，畫面較窄時可縱橫捲動。排列以年級順為優先，5、6年級置於1～4年級之下。前置關係的線會避開其他節點繞道，僅排在同一列並不代表依賴關係。

沒有前置的技能從一開始就解鎖，若有多個前置，則需要全部精通。狀態區分為鎖定、NEW、練習中、精通。一般的精通條件為至少有6題的歷史，且最近6題中有5題以上首次答對。一旦精通的技能，即使答錯也不會退回。程度測驗的批次賦予是這個次數條件的例外。

### 6.3 技能的星星

精通後會依序獲得☆1～☆5。必須逐段滿足條件，若已滿足，同一次判定可一次升多段。合計最大為290。

速度的判定使用每題的回答時間除以基準時間所得的比率。基準時間為 `第一個格的連擊時間 + max(0, 回答格數 − 1) × 普通格的連擊時間`。只從對象中首次答對的問題求出比率的中位數。

| 星 | 條件 |
| --- | --- |
| ☆1 | 已精通 |
| ☆2 | 最近20題齊全，首次答對率0.9以上 |
| ☆3 | 最近10題齊全，其中5題以上首次答對，且時間比率的中位數在1以下 |
| ☆4 | 最近3題全部首次答對，且各題的日期在☆3獲得日的7天之後 |
| ☆5 | 最近20題齊全，首次答對率0.95以上，時間比率的中位數在0.6以下 |

☆4的3題不限於同一天。星星在一般的遊玩或休息時不會減少，但會在技能的記錄刪除與全部重設時消失。說明畫面會顯示下一顆星的條件、目前的值、已解的問題數、最短的作答時間。

### 6.4 生鏽

將已精通且距離最後一次首次答對已過 `21 × 86400000` ms以上的技能列為候選，依最舊的順序最多對3項顯示「生鏽」。若沒有首次答對的日期時間，則依程度測驗的賦予日期時間、精通日期時間的順序參照。

將生鏽的技能首次答對1題就會被磨亮，在保留星星的情況下消除記號。因為磨亮了，可能會有另一個舊技能成為顯示對象。用於我的程度的複習與磨亮的今日任務。

### 6.5 技能的記錄刪除

對有記錄的技能長按600ms，或取得焦點後按下 Delete，就會開啟確認。若從按下的位置移動超過10px，就會中止長按操作。

確定後會刪除該技能以及直接、間接依賴它的技能的記錄、星星。所選的技能若前置仍存在則回到NEW，若前置不齊則回到鎖定。歷史、複習、累計統計、獎盃、收藏、已程度測驗的狀態則會保留。

## 7. 持續進行的機制

### 7.1 歷史、行事曆、簽到獎勵

在基本結果保存歷史，並在加碼關結束後更新同一筆歷史的得分、追加答對數、可惜、多巴。最多保留3000筆。行事曆會顯示每一天的最高得分與遊玩次數，並可從日期開啟詳細內容。可以移動到過去的月份，但不會前進到未來的月份。

連續天數以今天為起點計算，若今天還沒遊玩則以昨天為起點。也會顯示最長紀錄與簽到貼紙的張數。遊玩日與簽到日不同，光是開啟標題並不算遊玩的日子。

簽到獎勵依裝置的日期每天1次。以星星、愛心、花、音符、幸運草、小紅花、皇冠的7天週期領取貼紙。若中間夾了未設為免計的缺席日，週期就會從頭重新計算。貼紙在開啟顯示的時點即算取得，即使關閉或重新載入，同一天也不會重複領取。

### 7.2 免計鐵鎚

1支可將沒有遊玩的1天設為免計，把遊玩、簽到的連續串接起來。不會將該天加到遊玩天數，也不會補上休息日的貼紙。初始持有1支，持有上限為3支。

當最後遊玩的日子在最近7天以內，且到昨天為止的空缺日子能以持有數全部填補，並能守住2天以上的連續時，會在標題每天1次建議使用。拒絕的當天不會再次建議。使用後會在行事曆蓋上免計的章。使用歷史最多50筆。

### 7.3 今日任務

依裝置的日期，以及該天挑選時點的記錄，決定並保存2個簡單的與1個費時的。同一天即使變更設定也不會重新挑選。日期改變後的更新處理會切換到新的清單。候選為固定的11種，以及依生鏽狀況的1種。

| 名額 | 候選與達成條件 |
| --- | --- |
| 簡單 | 完成1回、5連擊、首次答對5題、複習1題、NEW的技能1題 |
| 費時 | 前往加碼關、加碼關5題、20連擊、完成2回、依年級完成1回、NEW或練習中的技能10題、指定技能首次答對3題 |

若沒有複習、NEW的對象，就排除該候選。加碼關相關的條件是最近5筆歷史中有加碼關的記錄，20連擊的條件是 `題數 × 平均回答格數 >= 26`，練習中10題的條件是已程度測驗且有未精通的候選。同一天不會重複同一個指標的任務。

所需時間的篩選模型，將1回設為 `(題數 × 18 + 預計進行加碼關時90 + 30) / 60` 分鐘。首次答對5題預計需 `ceil(5 / (題數 × 0.7))` 回，練習中10題預計需 `ceil(10 / (題數 × 0.6))` 回，20連擊預計需2回。複習以最多10題計算，重疊在模式間可共同達成的項目，選出合計15分鐘以內的組合。這只是估計，並非限制實際所需的時間。

磨亮的候選在有生鏽的日子裡，若源自日期的亂數小於0.5，且最近7天提示的次數未滿2次，就會成為選擇對象。可從標題開始對象技能的練習，達成需要以同一技能首次答對3題。與讓生鏽本身消失的1題條件不同。

進度會在遊玩中累加，達成時在畫面上緣通知。複習也會累加到共通的完成、首次答對、連擊條件。3個全部達成時，當天可領取1支鐵鎚，僅限1次，並在行事曆加上記號。若已達持有上限則只有演出，獎勵不會保留到日後。

### 7.4 獎盃

定義了12個分類、39個系列、306種。分類為持續、大量、技能、成長、加碼關、連擊、精準、多巴、複習、年級、收藏、秘密。達成各系列的階段即可獲得，已取得的會保留。

獲得判定在結果、最終結果、標題等處進行，遊玩中不會開啟獲得對話框。一次的通知最多6件與剩餘件數。從既有記錄首次判定時，會將已達成的部分批次通知。

清單以「全部／已獲得／尚未」篩選，開啟系列後可確認所有階段、獲得日期、獎勵。「即將」會顯示接近下一個條件的12件，並排除秘密、多巴、單次條件。等級為銅、銀、金、彩虹，單獨的階段為金，多階段的最後為彩虹，秘密則有專用顯示。

### 7.5 與上次比較

在基本結果中，將同一技能相較於以前記錄有進步的部分以「進步了！」顯示，最多3行。本次與比較對象雙方都需要3題以上。比較對象為前一次遊玩的日子、21天以上前最近的日子、最初解過的3題。不會只把同一天內過去的回數當作比較對象。

作答時間以每個回答格的平均進行比較，顯示則換算為本次平均格數下的每題秒數。以時間縮短10%以上，或首次答對率改善10個百分點以上的項目為候選。每個技能挑選最大的1項改善，整體則依改善幅度由大到小顯示。若沒有改善就不顯示。程度測驗、示範、停止成長記錄的確認用 URL 不在對象內。

### 7.6 時光膠囊

從每個技能保存的最初3題中，挑選已精通、且距離解題時點已過 `30 × 86400000` ms以上的未使用問題中最舊的一題。

一般的我的程度、依年級、練習的基本組合若有4題以上，會取代以0為起始編號的第 `max(1, min(N−2, floor(N/2)))` 題。程度測驗、複習、加碼關、示範、停止成長記錄的確認用 URL 不在對象內。1天最多1題，由於會保存預告結束時點的日期，之後即使中斷，同一天也不會再次提示。問題完成的時點即成為已使用。

以信封的預告與橘色邊框，讓人能看出是過去的問題。比較上，若本次的時間未滿過去的0.95倍則顯示時間縮短，否則顯示答錯次數的減少，兩者皆無則顯示再次解開與日期。剛好縮短5%時不會顯示為時間縮短。

## 8. 多巴基與演出、音效

多巴基原則上不使用語言。造形的基準為 `docs/dopakichi.svg`。具有大的橫向耳朵、橫向寬闊的圓頭、奶油色的臉與腹部、雙重圓圈的眼睛、纖細的手臂與藍色的腳。基本色為粉紅 `#FF97BF`、奶油 `#FFF3E4`、耳的內側 `#FFE6F0`、藍 `#2F79F7`、輪廓 `#000000`。

輸入的數字會用空著的手搬運。左右手可以搬運不同的數字，判定與搬運分開，不會讓下一次輸入等待。中途答對、最終答對會使用跳躍、拍手、旋轉等，答錯則先崩解再回復。答錯的演技有10種，開頭為4種，中段為8種，強度0.6以上則從10種中，避開與前一次相同的來挑選。

設基本題的問題編號以0為起始為 `i`、題數為 `N`，則演出強度為 `E = 0.08 + 0.92 × (i/(N−1))^1.3`。只有1題時設 `E = 1`。加碼關對於完成數 `k`，為 `tier = floor(k/3)`、`E = 1 + min(0.5, tier × 0.1)`。

依強度疊加背景、小紅花等答對記號、紙吹雪、星星、煙火、硬幣、觀眾、行進、伸手、燈飾、搖晃。終幕從巨大多巴基、煙火大會、火箭、遊行中選擇，最後顯示100分。維持輸入與數字鍵盤的配置、直式位數的對應。

音樂與音效以 Web Audio API 合成，不載入外部的錄音素材。基本為馬林巴進行曲，加上8位元、祭典樂、銅管樂、電子樂共5首。使用振盪器、雜訊、濾波器與殘響等，階段性地疊加打擊樂器、低音、和音、旋律。

基本題的節奏為 `112 + min(1, E) × 16` BPM，一般的最初為113.28 BPM，最後為128 BPM。最終題會從基準升高2個半音。加碼關為 `134 + tier × 5` BPM，調性從基準升高 `2 + min(tier, 5)` 個半音。轉調有上限，節奏則沒有依此式的固定上限。

以聲音補足按鍵、數字落定、答對、答錯、多巴的里程碑、時鐘等，音高會與樂曲的和音同步。聲音的開始使用瀏覽器要求的使用者操作。背景採用 WebGL，無法使用或情境遺失時會切換到 CSS 的背景。

## 9. 設定與無障礙

| 設定 | 內容與初始值 |
| --- | --- |
| 題數 | 6、10、14題。初始值10題 |
| 音效 | 開／關。初始值開。也可從遊玩畫面的靜音變更 |

| 動作強度 | 0～100%。未設定時，若裝置指定減少動態則為0%，其餘為100% |

| 全部重設 | 進行2次確認後將裝置內的資料初始化 |

動作強度會反映在粒子量、搖晃、閃光、背景、觀眾、多巴基的大幅動作上。0%時會停止主要的移動、搖晃、閃光，導引也會變成靜止姿勢。不過並非停止所有描繪的功能，一般畫面的呼吸動作等與少量粒子仍有保留的處理。操作數值時可在設定畫面試看反應。計算的判定與得分規則不會改變。

Escape 會關閉已開啟的對話框，在標題以外的畫面則開啟「要回到標題嗎？」的確認。以「繼續」為初始焦點，確認期間會停止輸入、基本題的經過時間、加碼關與連擊的期限、每題的計測。中斷前已完成的問題之熟練度等會保留。若在基本結果之前，不會建立完成歷史。示範中的 Escape 為結束示範。

備有按鈕的無障礙名稱、焦點顯示、數字以外的標籤、導引內的焦點循環。並不保證僅靠螢幕閱讀器就能完整遊玩，或能在所有裝置上操作。

高度700px以下時會調整題目紙、演出區域、留白，讓數字鍵盤的最下排也能容納於畫面內。即使是較短的畫面，也會維持按鍵高度48px。

全部重設的第1次以「全部重設」顯示將刪除的內容，第2次以「真的要刪除嗎？」確認無法復原。兩者的初始焦點都是「取消」。取消、Escape、點擊背景都不會刪除。第2次確定後，會刪除所有具有前綴 `dopa-drill` 的儲存鍵，捨棄記憶體的快取並重新載入。無關的鍵則會保留。

初始化對象為設定、歷史、熟練度、星星、成長記錄、獎盃、收藏選擇、貼紙、今日任務、道具、初次導引狀態。重新啟動時，初次導引與初期道具等會重新建立。即使瀏覽器拒絕刪除，處理也不會以例外結束，但無法保證已保存的資料會被清除。

## 10. 儲存與隱私

儲存位置為瀏覽器的 localStorage，鍵為 `dopa-drill:v1`，資料的版本為1。沒有輸入姓名等個人資訊的欄位，應用程式不會將學習記錄傳送到伺服器。沒有廣告、外部分析、排行榜、裝置間的同步。運作方式是從配信伺服器取得遊戲的靜態檔案。

在儲存區域無法使用、讀取失敗、JSON 損毀的情況下，會以初始狀態啟動，即使儲存失敗也會繼續當下的遊戲。清除瀏覽器資料、儲存限制、在別的瀏覽器或配信來源使用時，記錄無法延續。

| 記錄 | 內容、上限 |
| --- | --- |
| 設定、導引 | 題數、音效、音量、動作、導引已顯示 |
| 完成歷史 | 最多3000筆。日期、模式、得分、答對、可惜、基本時間、多巴、加碼關 |
| 技能 | 最近6題的首次答對、最近24個簽名、最近30題的時間、格數、答錯、日期、最近60天的彙總、最初3題本身、最後的首次答對、精通日期時間、星星 |
| 複習 | 最多40題的問題本身 |
| 累計統計 | 完成問題、格、首次答對、答錯、基本完成與模式、基本時間、最大多巴、加碼關、最大連擊、複習、遊玩天數、磨亮次數、比較、膠囊 |
| 持續、獎勵 | 貼紙、簽到日、免計日、鐵鎚、今日任務、已獲得的獎盃、演出的選擇 |

1題的作答時間為從受理輸入到最後一次正確輸入為止，不含問題之間的演出與確認對話框。累計的問題、格、答錯會在問題完成的時點加算，因此中途結束的未完成問題之操作不會列入統計。

在還沒有統計的儲存資料中，會從歷史初始化可取得的值。過去的格數與最大連擊等無法從歷史得知的值，則從0開始計測。確認用 URL 並非停止全部儲存的功能。具體的差異記載於下一章。

### 11.2 啟動與測試

從儲存庫的根目錄，例如以下指令即可進行靜態配信。以顯示出的伺服器位址開啟 `/app/`。由於使用 ES Modules，請不要直接開啟 HTML 檔案，而是以 HTTP 配信。

```sh
python3 -m http.server 8000 --bind 0.0.0.0
```

使用 Node.js 的測試以下列指令執行。

```sh
node --test tests/*.test.mjs
```

產品的測試為 `tests/app_*.test.mjs` 的11個檔案、58件。上述指令也包含一併附上的其他測試，因此整體件數依散布物而異。在只顯示檔案單位件數的 Node.js 環境中，於對應的環境加上 `--experimental-test-isolation=none` 即可彙總個別測試。

檢查問題生成、輸入步驟、得分、儲存與重設、技能、星星、出題計畫、成長比較、今日任務、獎盃、解鎖演出、導引的配置計算。自動測試的成功不能替代實機的描繪、音質、操作感的驗證。

### 11.3 確認用 URL 參數

以 `/app/?count=6&seed=123` 的方式指定。

| 參數 | 動作 |
| --- | --- |
| `count=6`、`count=10`、`count=14` | 選擇啟動時的題數 |
| `seed=<數值>` | 固定用於問題選擇、生成等的亂數。不會固定到所有視覺效果的亂數 |
| `extra=<秒>` | 取代加碼關預設的90秒。開始時的900ms加算為共通 |
| `skill=<技能ID>` | 將一般的問題選擇取代為該技能。與複習或固定模板併用時，選擇處理有優先順序 |
| `demo` | 從我的程度的入口開始固定模板的基本組合。第一題為27＋35。不進行自動操作 |
| `capture` | 收集音訊事件的確認路徑。抑制一般的即時音訊輸出與自動導引、標題獎勵通知等 |

在 `skill` 與固定模板的遊玩中，會停止一般的作答時間、成長統計、今日任務，但完成歷史與複習會保存。`skill` 中若出題計畫為程度測驗，該計畫端的精通賦予與檢查完成的儲存也會運作。獎盃判定在 `skill` 與 `capture` 會停止，但僅指定 `demo` 時不會停止。`capture` 中一般的進度、歷史、統計的儲存仍會繼續。請不要將這些當作不留記錄的練習功能。
